Install it in one command

Linux and macOS. The script clones the repo, builds zen-cli in release mode, and puts the binary in ~/.local/bin/zen. No sudo needed. Inspect the script before running it if you want to.

curl -fsSL https://raw.githubusercontent.com/7enlabs/zencode/main/install.sh | sh

Windows (PowerShell) and full details: INSTALL.md. You’ll need Git and a Rust toolchain (cargo) first — the build takes a few minutes.

How we measure cost

The CLI tracks its own usage. zen cost prints tokens used and what they cost, per model — including a line that says the session cost $0.00 when everything ran on free models.

Example output format:

$ zen cost
Session cost: <session-id>
  <model> (<provider>)
    12,400 input · 3,100 output tokens · $0.42
Totals: 12,400 input · 3,100 output · 15,500 tokens

Total cost: $0.42

Machine-readable too: zen cost --json. At the end of the pilot, paste the output — that’s the cost number. Hours saved are your own estimate: note tasks where the CLI did the work, and roughly how long they would have taken by hand.

FAQ

Is ZenCode CLI free?

Yes. The core is MIT-licensed and free forever. There are no seat fees and no paywalled core features.

Where does my code and data go?

Nowhere through us. You bring your own API key (BYOK) — the CLI talks to your model provider directly. We don’t run a server in the middle, and we don’t see your code.

Do I need a card?

No. There is nothing to pay for in the pilot, and the core stays free after it.

What happens after the pilot?

You keep using it. The pilot ends; the CLI stays free. If the numbers are useful, we may publish a case study — only with your permission, and only with the numbers you agree to share.
